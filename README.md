## ✈️ AIRLINES MANAGEMENT SYSTEM

A simple system to manage **flights, passengers, bookings, and tickets** with CRUD operations using **Python, Streamlit, and SQL**.

---

## 🛠️ FEATURES
- **Flight Management:** Add, update, delete, and view flights.  
- **Passenger Management:** Manage passenger details.  
- **Booking System:** Book flights, view history, cancel bookings.  
- **Ticket Management:** Assign and manage tickets.  
- **Search:** Search flights by destination, date, and available seats.

---

## 👨‍💻 TECHNOLOGIES
- **Python** – Backend logic  
- **Streamlit** – Interactive frontend UI  
- **SQL/MySQL** – Database management

---

## 🗂️ DATABASE TABLES
- **AIRPORT** – Airport details  
- **PAYMENT** – Booking payments  
- **PASSENGER** – Passenger info  
- **AIRLINE** – Airline info  
- **BOOKING** – Flight bookings  
- **FLIGHT** – Flight details  
- **TICKET** – Passenger tickets  
- **USERS** – Admin credentials
